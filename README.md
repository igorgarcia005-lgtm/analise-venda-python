# Análise de Vendas com Python

Pequena análise exploratória de um DataFrame de vendas,
feita com Python e pandas a fim de exercitar exemplos reais

## O que o projeto faz
- extrai dados de uma tabela excel
- trata e limpa os dados
- depois foi feito uma pequena analise com alguns objetivos de achar maior cliente qual cidade mais vendeu

## Tecnologias
Python, pandas, Jupyter Notebook

## Como rodar
1. Clone o repositório
2. Instale as dependências: pip install pandas matplotlib
3. Abra o notebook no Jupyter ou no VS Code
